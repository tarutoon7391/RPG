# BATTLE ISLAND（8人用バトロワの島）

いまは **マップだけ**（歩き回る・降下・宝箱の置き場所・抜け道）。戦闘・アイテム・オンラインはまだ無い。

## ルールの予定（決まっていること）

- 最大 8 人。個人戦とチーム戦の両方（チーム人数 1〜4 をロビーで選ぶ。6 人なら 2 人×3 など）
- チーム戦：味方への攻撃なし・ダウン→味方が蘇生・全員ダウンで脱落
- 勝利判定は「生き残りが 1 チームだけ」で共通（個人戦は 1 人チーム扱い）

## 島（`public/src/br/`）

約 1km 四方。地形は関数だが、場所は手で固定している（`island.js` の AREAS・RIVER・BRIDGES）。北 = -z。

| エリア | 場所 | 特徴 |
| --- | --- | --- |
| 王都アステリア | 中央 | 城壁・王城・家が密集。近距離戦 |
| 雪山砦 | 北の山頂（標高 130m 前後） | 四角い砦。見晴らしがいい |
| 東の古代遺跡 | 東の台地 | 柱・崩れた壁・倒れた柱で隠れられる |
| 西の深い森 | 西 | 木が密集。川の向こう側 |
| 南の港 | 南の岬 | 倉庫・木箱・桟橋・乗れる船 |
| 霧の沼地 | 南東 | 低く平ら。高床小屋 |
| 風車の丘 | 北東 | 回る風車 |
| 灯台の崖 | 南西の台地 | 崖の上の灯台 |
| 大河 | 北の山から南西の海へ | 島を東西に分ける。橋 3 本（泳いでも渡れる） |

- 見張り台 4 つ（坂で上れる）
- 地下の抜け道 A〜E（どれからでも他の入口へ出られる）
- 宝箱 39 個（エリアごとに数を決めて配置。中身は今後）

## 仕組み

- 地形・草木・当たり判定は広大マップと共通（`world/tiles.js`・`props.js`・`colliders.js`）
- 乗れる板（橋・桟橋・甲板・坂）は `br/platforms.js`。地面の高さ = max(地形, 板)
- 建物は `br/build.js`。最初に全部作る（島が小さいので出し入れしない）
- 降下：上空 140m からゆっくり落ちて、空中でも動ける
