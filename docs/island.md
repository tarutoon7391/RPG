# BATTLE ISLAND（8人用バトロワの島）

いまは **マップだけ**（歩き回る・降下・宝箱の置き場所・抜け道）。戦闘・アイテム・オンラインはまだ無い。

## ルールの予定（決まっていること）

- 最大 8 人。個人戦とチーム戦の両方（チーム人数 1〜4 をロビーで選ぶ。6 人なら 2 人×3 など）
- チーム戦：味方への攻撃なし・ダウン→味方が蘇生・全員ダウンで脱落
- 勝利判定は「生き残りが 1 チームだけ」で共通（個人戦は 1 人チーム扱い）

## 島（`public/src/br/`）

約 1km 四方。地形は関数だが、場所は手で固定している（`island.js` の AREAS・RIVER・BRIDGES）。北 = -z。

| エリア | 場所 | 特徴 |
| --- | --- | --- |
| 王都アステリア | 中央 | 城壁・王城・家が密集。近距離戦 |
| 雪山砦 | 北の山頂（標高 130m 前後） | 四角い砦。見晴らしがいい |
| 東の古代遺跡 | 東の台地 | 柱・崩れた壁・倒れた柱で隠れられる |
| 西の深い森 | 西 | 木が密集。川の向こう側 |
| 南の港 | 南の岬 | 倉庫・木箱・桟橋・乗れる船 |
| 霧の沼地 | 南東 | 低く平ら。高床小屋 |
| 風車の丘 | 北東 | 回る風車 |
| 灯台の崖 | 南西の台地 | 崖の上の灯台 |
| 大河 | 北の山から南西の海へ | 島を東西に分ける。橋 3 本（泳いでも渡れる） |

- 家はすべて中が空洞で、正面（+z 側）の扉から入れる
- 大きい建物は中に階段があって 2 階・屋上へ上がれる：王城（1階の大広間・2階・屋上）、雪山砦の本丸（2階・屋上）、港の倉庫（2階）
- 螺旋階段の塔：王城の四隅に 4 本（高さ 30m）、雪山砦の四隅に 4 本（14m）、灯台（24m）。てっぺんは外に張り出したバルコニーで、手すりの低いところから撃ち下ろせる
- 塔のバルコニー・王城や砦の本丸の屋上からは、ジャンプで手すり（胸壁）を越えて飛び降りられる。歩くだけなら落ちない。落下ダメージはまだ無い
- 雪山砦は山頂を広めに平らにして、壁と塔の土台を地面の下まで伸ばした（宙に浮かない）
- 見張り台 4 つ（坂で上れる）
- 地下の抜け道 A〜E（どれからでも他の入口へ出られる）
- 宝箱 39 個（エリアごとに数を決めて配置。中身は今後）

## 武器（`public/src/weapons/`）

- 形は 3DGAME の RPG の武器 96 種をそのまま移植（`shapes_a〜d.js`・`kit.js`・`model.js`。形の id = 3DRPG の職業 id）
- `catalog.js`：96 種の名前・種類（剣・大剣/大鎌・刀・短剣・槍・斧・鈍器・拳・杖・弓・銃・重火器・投げ物・変わり種）・攻撃力などの下書き
- スキン＝レア度 5 段階：コモン（元の色）／アンコモン（翠玉）／レア（蒼鋼）／エピック（紫晶）／レジェンド（黄金・キラキラ付き）。金属・飾り・光る部分の色が変わる
- 落ちている場所：家（3 軒に 1 軒くらい）・王城の各階と屋上・塔のてっぺん・砦の本丸・倉庫の 2 階・船・見張り台・高床小屋。高いところほど良いレア度が出やすい
- 宝箱を開けると 1〜2 本出てくる（ちょっと良い物が出やすい）
- 持てるのは 3 本（1〜3 キー／一人称ならホイール／タップで切り替え）。満杯で拾うと今の武器と入れ替え
- 左クリック（スマホは攻撃ボタン）で攻撃。押しっぱなしで武器の速さで連続。ダメージはまだ無い
- 振り方は 3DRPG の一人称の動きを移植（`weapons/viewmodel.js`）：剣は横薙ぎ→逆の横薙ぎ→振りかぶって縦斬り（斧・鎌は刃を縦に）、槍は突き、拳は左右交互の突き、銃は反動と銃口の光、杖は前へ突き出して放つ
- 一人称だけ（三人称は無し）。画面中央に十字。攻撃は十字の先へ飛ぶ（中央からのレイの当たった所）
- 飛ぶ物（`weapons/projectiles.js`）：銃＝曳光弾、弓＝矢、杖＝魔法の玉（スキンの色）、ロケット・砲弾・爆弾＝爆発、火炎放射＝炎、光線銃＝ビーム、投げ物＝回る刃、近接＝斬撃の弧と火花
- 覗き込み（`weapons/sights.js`）：PC は右クリックを押している間、スマホは照準ボタン
  - スコープ（スナイパー）：画面いっぱいの丸いスコープ、手は隠す、大きくズーム
  - ホロサイト（ガトリング・火炎放射・ロケット・重砲・粘着弾・光線銃・吸い込みラッパ）：ガラス枠に赤い円と点
  - アイアンサイト（リボルバー・ハンドキャノン・注射器ガン）：照門のくぼみと照星を合わせる
  - 弓（ロングボウ・クロスボウ・ハンドクロスボウ・パチンコ）：矢じりの目印
  - 覗き込み中は視点の速さもズームに合わせてゆっくりに、ダッシュはできない
- 一人称の手と武器は別のシーンで上に重ねて描く（engine の overlay）。三人称は右手に持つ（3DRPG と同じ持たせ方）
- 武器図鑑（タイトル・ポーズから）：種類で絞り込み、スキンを切り替えて回して見られる

## 仕組み

- 地形・草木・当たり判定は広大マップと共通（`world/tiles.js`・`props.js`・`colliders.js`）
- 乗れる板（橋・桟橋・甲板・坂・階段・2階の床）は `br/platforms.js`。地面の高さ = max(地形, 今の高さ+1.3m 以内の板)
- 中に入れる建物の部品は `world/interiors.js`（空洞の家・階段つきの建物・螺旋階段の塔）
- 当たり判定は top（これより上なら通れる）と bot（体がこれより下なら通れる）で階ごとに分けられる
- 建物は `br/build.js`。最初に全部作る（島が小さいので出し入れしない）
- 降下：上空 140m からゆっくり落ちて、空中でも動ける
