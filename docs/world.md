# ワールドの仕組み

## 広さとステージ

- ワールドは一辺 `size`（既定 32km = 32768m）の正方形。中心が原点、北が -z
- 2048m 四方を 1 **ステージ（リージョン）**とする。32km なら 16×16 = 256 マスのうち陸のもの（約 190）がステージ
- ステージ番号は王都から近い順。各ステージに「ステージ碑」が 1 つあり、そのステージのダンジョン一覧が読める
- 大陸の外周は海（泳げる。深いところは泳ぎになる）

## 地形（`world/terrain.js`）

座標 → 高さ・色 の関数だけで決まる。気温（北ほど寒い）・湿り気・山・火山のノイズから
草原 / 森 / 砂漠 / 雪原 / 湿地 / 火山 / 山岳 を連続的に混ぜる。町やダンジョンの入口は周りを平らにする。

## 描画

| 部分 | ファイル | やり方 |
| --- | --- | --- |
| 地形 | `world/tiles.js` | クアッドツリー LOD。33×33 頂点のタイルを距離で分割（最小 64m）。継ぎ目はスカートで隠す。未作成のタイルは親で代用 |
| 草木・岩 | `world/props.js` | 128m セルごとにシードで配置 → 近くのセルだけ InstancedMesh にまとめる |
| 建物 | `world/structures.js` | 距離で出し入れ。1 件 = 1〜2 メッシュ（mergeGeometries）。塔・城は遠くから見える |
| 地図 | `ui/mapworker.js` | Web Worker で 1024×1024 の地図を裏で描く |
| ダンジョン | `dungeon/gen.js`・`build.js` | 1 フロア = 部屋＋L 字通路のグリッド（1 マス 4m）。壁・床・柱・松明は InstancedMesh |

## ダンジョン

- 種類：洞窟・古代遺跡・塔（上へ）・神殿・地下墓所・氷穴・溶岩洞・魔王城（上へ 30 階）・王城（上へ 6 階）
- 難しさ（★1〜6）は王都からの距離。階数は 4〜30。フロアの広さは 25〜121 マス四方で深いほど広い
- 最深部の宝を調べると「踏破」としてセーブに残る（中身は今後）
