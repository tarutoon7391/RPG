# RPG

ブラウザで遊べる 3D ゲームの土台。2 つのマップがある。

- **`/`：BATTLE ISLAND** … 8人用バトルロイヤルの島（約 1km 四方・手作り配置）。いまはマップだけ → `docs/island.md`
- **`/world/`：広大マップテスト** … 32km 四方の大陸（下の説明）→ `docs/world.md`

## 広大マップテスト（/world/）

- ステージ（地方）約 190・町 約 55・ダンジョン 約 350（全部で 3,500 階くらい）
- 地平線まで全部描く（クアッドツリー LOD）。近くは 2m 間隔、遠くは数 km の粗いタイル
- ダンジョンは入ると階層フロアが自動生成される（部屋＋通路、深いほど広い）
- `?size=128` で 128km 四方（ステージ約 3,000・ダンジョン約 5,600・全 5 万階以上）まで試せる

## 起動

```bash
npm install
npm start          # http://localhost:3000
npm run smoke      # 構文・import・サーバー応答のチェック
```

## 操作

| PC | スマホ | 内容 |
| --- | --- | --- |
| WASD | 左スティック | 移動（Shift／いっぱいに倒すとダッシュ） |
| マウス（クリックでロック） | 右側ドラッグ | 視点 |
| Space | ジャンプ | ジャンプ |
| F | 調べる | 看板・ステージ碑を読む／ダンジョンに入る・階段 |
| M | 🗺 | ワールドマップ（クリックでテスト用ワープ） |
| V | 視点 | 一人称／三人称 |
| G | 爆速 | テスト用の高速移動（150m/s） |
| F3 | - | デバッグ表示（FPS・描画回数・タイル数など） |
| Esc | ⏸ | ポーズ（描画距離などの画質設定） |

## URL パラメータ（/world/）

- `?size=8|16|32|64|128` … ワールドの一辺（km）。既定 32
- `?seed=数字` … 地形のシード
- `?touch` … PC でもタッチ操作の UI を出す
- `?debug` … `window.__rpg` にテスト用の関数を出す
